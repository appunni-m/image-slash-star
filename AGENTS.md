# Repository instructions

Follow the requirements in [CLAUDE.md](CLAUDE.md) that apply to the current
task, including codec safety, parity, and release rules when relevant.

Keep work scoped to the user's request. Unrelated roadmap items are not
prerequisites for completing a task.

Use normal source search and repository commands. Run checks appropriate to
the changed files and behavior. Documentation-only and administrative changes
do not require the full codec, feature, target, or coverage campaigns; preserve
those gates for affected implementation changes and release verification.
